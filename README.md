# Shrishti Portfolio

A modern, responsive, ultra-clean Light Theme portfolio website built with React.js, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Light Minimalist Theme**: Clean slate whites, subtle glassmorphic cards, and vibrant indigo/purple accent highlights.
- **Scroll & Appear Animations**: Smooth scroll-triggered reveal animations across all sections using Framer Motion.
- **Animated Vertical Work Timeline**: Scroll-driven timeline progress line with sequentially popping job nodes.
- **Staggered Grid Reveals**: Dynamic sequential reveals for technical skills and featured projects.
- **Juicy Micro-Interactions**: Hover lift effects, shadow expansions, bouncy button feedback, and responsive social icon transitions.
- **Interactive Persona Configurator**: Interactive toggle card showcasing Frontend Engineering, UI Craftsmanship, and Hybrid capabilities.
- **Functional Contact Section**: Copyable direct email/phone buttons and message form.

## 🛠️ Tech Stack

- **Framework**: React.js + Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Design System**: Stitch MCP Light Minimal-Luxe System

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
